# Portfólio QA Manual | Sabrina

Foco em Testes Manuais, Gherkin e Cobertura de Cenários.

### Projeto 1 - Funcionalidade Esqueci Minha Senha
Teste da funcionalidade de recuperação de senha com foco em experiência do usuário e validações.

**Cobertura:**
- Caminho Feliz: email válido
- Caminho Triste: email não cadastrado
- Caminho da Maldade: formatos inválidos e campo vazio

**Técnicas aplicadas:**
- Gherkin com Scenario Outline
- Tabela de exemplos (Teste.com, Teste@.com, Teste@gmail..com, teste@@@gmail.com)
- Tags @regressivo

**Arquivo:** `recuperar-senha.feature`
